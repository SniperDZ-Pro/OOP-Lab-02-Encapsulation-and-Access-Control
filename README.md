# OOP Lab 02: Encapsulation and Access Control

Welcome to Lab 02. After modeling classes and objects in Lab 01, this session introduces **encapsulation** — the first principle of data protection in Object-Oriented Programming — using Java and the Eclipse IDE.

## Objective
Understand and apply encapsulation by hiding an object's internal state behind `private` attributes and exposing controlled access through `public` getters and setters. You will learn why direct attribute access is dangerous and how to build a safe, well-defined interface for your classes.

## Contents
- `Book.java`: The encapsulated class with private attributes and getters/setters.
- `MainApp.java`: The main execution program.
- **Individual Tasks:** 6 hands-on exercises to add attributes, read via getters, write via setters, and observe compile-time protection.
